## How to use transparent PNGs

1. **Keep it PNG or WebP.** JPG has no transparency, so cut-outs saved as JPG get a white box.
2. **Go big.** One large cut-out reads better on a phone screen than several small ones.
3. **Add a soft shadow** under the object so it sits on the design instead of floating.
4. **Compress for the web.** Large PNGs slow pages down; run them through a compressor first.
5. **Don't stretch.** Resize from a corner, or upscale small files before enlarging them.

Example in HTML/CSS:

```html
<div style="background:#16a34a;padding:24px;text-align:center">
  <img src="your-image.png" alt="Product cut-out" style="max-width:320px;filter:drop-shadow(0 10px 12px rgba(0,0,0,.25))">
</div>
```
